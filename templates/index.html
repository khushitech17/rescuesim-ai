How It Works

The AI methods behind the simulation.

The plan is the search grid

Every wall, door, corridor and room on the floor plan is drawn from the same 0/1 grid the algorithms search. A door is one free cell cut into a wall; routes can only pass through real openings.

Search for each person

Every occupant runs the chosen search and stops at the nearest reachable exit. If none is reachable, the occupant is marked trapped.

BFS, DFS and A*

BFS (queue) finds the fewest steps. DFS (stack) finds an exit but not always the shortest route. A* uses f(n) = g(n) + h(n) with the Manhattan distance to the closest exit.

Collision-free movement

Two occupants never share a cell. An occupant waits if the next cell is taken. If nobody can move, blocked occupants are re-planned around each other; if that fails, a movement conflict is reported.

Limits

Educational model only: no fire spread, speed differences or panic behaviour. It is NOT a certified or real-world emergency evacuation planning system.
